# Simple Weather Forecast App

A weather application built with React that displays current weather conditions for a searched city.

## Features

- Search weather by city name
- Display temperature in Celsius
- Show weather conditions and description
- Light and dark mode
- Responsive user interface

## Technologies Used

- React
- Vite
- Tailwind CSS
- Axios
- OpenWeatherMap API

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Hrishirajeev/Simple-Weather-Forecast-App.git
```

2. Open the project folder:

```bash
cd Simple-Weather-Forecast-App
```

3. Install dependencies:

```bash
npm install
```

4. Add your OpenWeatherMap API key to the application.

5. Start the development server:

```bash
npm run dev
```
